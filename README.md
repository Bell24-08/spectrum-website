# Spectrum Executive Search website

Static company profile site (English and Indonesian). No build step: open `index.html` or serve the folder.

- `index.html`: home (video hero, past clients, links to the other pages, WhatsApp contact)
- `about.html`: what we do, numbers, worldwide globe, profile video
- `how.html`: the four search steps and the top three industries
- `contact.html`: WhatsApp contact and Instagram
- `insights.html`: Insights articles
- `assets/js/i18n.js`: all English and Indonesian copy, plus the Insights articles (`ARTICLES`)
- `assets/js/site.js`: language switch, starfield, logo draw-on, client logos, step animations, globe
- `assets/img/clients/`: past client logos, each baked onto its own card image

Hosted with GitHub Pages from the `gh-pages` branch. After changing `main`, push it to `gh-pages` too (`git push origin main:gh-pages`).
